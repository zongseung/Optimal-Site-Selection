# MOSAIC — Wildfire Risk Analysis for Power Distribution Poles

[![Contest](https://img.shields.io/badge/2026_Weather_Big_Data_Contest-Topic_1_Disaster_Safety-1f6feb)](https://bd.kma.go.kr)
[![Award](https://img.shields.io/badge/🏆_3rd_Prize-KEPCO_President's_Award-FFD700)](https://www.kepco.co.kr)

**🏆 3rd Prize — KEPCO President's Award (한국전력사장상), 2026 Weather Big Data Contest (KMA · KEPCO)**

Physics-first wildfire risk classification for **1,387,831 power poles** in Gangwon Province —
a presence-only (PU) problem solved with $R = I \cdot S \cdot W$ decomposition, a 4-regime
mixture of experts, Bayesian posteriors (Poisson–Gamma / BYM2), and per-regime conformal coverage.
